# CSR 文档题注与交叉引用治理 Agent Demo

这是一个面向 **医药 CSR 中文报告** 的 Web Demo，用来演示 AI 写作下游 Agent 如何在不依赖 WPS Word 团队底层能力的情况下，先通过 OOXML 直接实现一条最小闭环：

1. 识别正文中的表格引用（如 `见表格14.1.1.2`）和图片引用（如 `如图 1 所示`）。
2. 识别表格上方的静态表题、表格内首行表题、图片邻近的图题。
3. 将静态题注转换成带 `SEQ` 字段的标准题注。
4. 建立旧编号到新编号的映射，支持三种编号策略。
5. 将正文引用改写为新编号，并写入 `REF` 交叉引用字段。
6. 中置信度项进入人工确认队列，用户可逐项确认或跳过。
7. 输出处理后 `.docx` 和审计报告。

> 这个项目用于和开发、WPS Word 团队讨论技术边界与底层 Skill 需求，不是生产级 Word 内核替代方案。

## 快速启动

### 方式一：本地一键启动并自动打开浏览器

```bash
python3 run_demo.py
```

如果是 Windows，也可以尝试：

```powershell
py run_demo.py
```

该方式会在你的本地电脑启动服务，并自动打开：

```text
http://127.0.0.1:8000
```

### 方式二：手动启动服务

```bash
python3 -m app.server
```

打开：

```text
http://127.0.0.1:8000
```

如果运行在 Cursor Cloud 等远程环境中，请通过 IDE/Cloud 的端口转发或预览地址访问 `8000` 端口。服务默认监听 `0.0.0.0:8000`，便于远程预览。

页面中可以先点击"下载示例文档"，再上传该文档进行扫描和执行治理。

## 运行测试

```bash
python3 -m unittest discover
```

## Demo 能力范围

当前 Demo 覆盖 PRD 中的以下核心功能：

### 表格支持
- `.docx` 文件读取，`word/document.xml` 结构解析。
- 表格对象识别。
- 静态中文表题识别（表格上方段落）。
- 表格首行/合并单元格内表题识别。
- 正文表格引用识别（`见表格14.1.1.2`、`如表 2 所示`、`参见统计列表 16.2.2`）。
- 题注字段写入：`SEQ 表 \* ARABIC`。
- 书签写入：`_CSR_Table_001`。
- 交叉引用字段写入：`REF _CSR_Table_001 \h`。

### 图片支持
- 文档内 `w:drawing` / `w:pict` 图片检测。
- 图片邻近图题识别（`图 14.2.1 研究流程图`）。
- 正文图片引用识别（`如图 1 所示`、`参考图 3`）。
- 图题注字段写入：`SEQ 图 \* ARABIC`。
- 图书签写入：`_CSR_Figure_001`。
- 图交叉引用字段写入：`REF _CSR_Figure_001 \h`。

### 编号策略
- **全文连续编号**：表 1、表 2、图 1、图 2（默认）。
- **按章节编号**：表 10-1、表 10-2（自动检测章节标题）。
- **保留原始编号**：沿用文档中的编号。

### 引用匹配
- 高置信度编号匹配：原始统计表编号、题注重排后的新编号。
- 重复局部编号隔离：多个章节都出现 `见表1` / `表1 xxx` 时，优先匹配引用段落后的最近同编号表。
- 语义邻近纠偏：结合正文整句和附近表/图题关键词匹配。
- 中置信度段落邻近匹配：如 `统计列表 16.2.2` 推荐匹配到同段落后的最近表格。

### 人工确认队列
- 中置信度引用进入确认队列。
- 用户可逐项「接受」或「跳过」。
- 支持「全部接受」快捷操作。
- 确认后的项目在执行时自动处理。

### 审计与可视化
- 10 步透明执行日志（解析 → 识别 → 创建 → 映射 → 匹配 → 改写 → 引用 → 确认 → 报告）。
- 审计 JSON 输出，每条修改含修改前后文本、置信度、匹配方法和原因。
- 审计报告记录编号策略、用户确认行为。

## 当前限制

为了保持 Demo 轻量可运行，当前没有引入 FastAPI、python-docx 或商业 Office/WPS SDK。实现采用 Python 标准库直接处理 OOXML，因此存在一些生产限制：

- 图片检测基于 OOXML `w:drawing` / `w:pict` 结构，不解析实际图片内容。
- 处理被命中的段落时会重建 runs，复杂局部样式可能丢失。
- 表格内首行表名会被原位覆盖成题注字段；生产版本应由 WPS Word Skill 判断是否需要转为表外标准题注。
- 段落邻近匹配仅作为中置信度推荐展示，Demo 默认不自动执行中置信度项。
- 当前语义能力是轻量关键词相似度 Demo，不等同于生产级医学语义模型；生产版建议由 Agent 侧结合 LLM/Embedding 与 WPS 对象级 Skill 共同完成。
- 字段显示值会写入文档，但最终字段刷新、兼容性和版式稳定性仍应由 WPS/Office 内核保障。
- 按章节编号策略使用简单的标题检测启发式，生产环境建议使用 WPS 提供的标题样式 API。

## 与 WPS Word Skill 的关系

这个 Demo 证明业务 Agent 可以在上层完成：

- CSR 规则理解。
- 正文引用识别（表格 + 图片）。
- 旧编号到新编号映射。
- 编号策略切换。
- 执行计划生成。
- 人工确认队列编排。
- 审计报告。
- 可视化执行日志。

但生产环境中，以下能力建议由 WPS Word 团队以 CLI/Skill 形式提供：

- `ParseDocumentStructure`
- `ConvertTextToCaption`
- `InsertCaption`
- `PreviewCaptionNumbering`
- `CreateBookmark`
- `ReplaceTextWithCrossReference`
- `UpdateFields`
- `ValidateReferences`
- `ValidateDocument`
- `CreateCheckpoint`
- `RollbackToCheckpoint`

业务 Agent 应调用这些对象级 Skill，而不是长期直接修改 OOXML。
